SET Theme Momentum

USไทย

ดูว่าเงินกำลังไหลเข้าหรือออกจากธีมไหนในตลาดหุ้นไทย เมื่อเทียบกับดัชนี SET · ธีม = กลุ่มบริษัทที่ได้รายได้จากเรื่องเดียวกัน (ตามแผนที่ธีมหุ้นไทย) ไม่ใช่หมวดของตลาดหลักทรัพย์ · ตัวเลขของธีมเป็นมัธยฐานของหุ้นสมาชิก ไม่ถ่วงน้ำหนักมูลค่าตลาด

เฝ้าดู

ภาพรวมวันนี้

แผนที่การหมุน (Rotation map)

ธีมที่ดีขึ้นมักเดินวนตามเข็มนาฬิกา: ตามหลัง → กำลังฟื้น → ผู้นำ → เริ่มอ่อนแรง → ตามหลัง

แกนนอน = RS-Level (แข็งแรงกว่าคนอื่นแค่ไหน) · แกนตั้ง = RS-Momentum (กำลังเร่งหรือแผ่ว) ทั้งคู่เทียบกับดัชนี SET และเทียบกับธีมอื่นในวันเดียวกัน (ธีมหลักเทียบกับธีมหลัก · ธีมย่อยเทียบกับธีมย่อย)

เส้นทางย้อนหลัง
ซูม
วิธีอ่านแผนที่นี้

1ตำแหน่งจุด = สถานะของธีมวันนี้

  • แนวนอน: แข็งแรงแค่ไหนช่วง 3 เดือน เทียบดัชนี SET และธีมอื่น — ขวาของเส้นกลาง = แข็งกว่าค่าเฉลี่ย
  • แนวตั้ง: แรงส่งช่วง 1 เดือน — เหนือเส้นกลาง = กำลังเร่งขึ้น · ใต้เส้น = กำลังแผ่ว

2สี่มุม

  • ผู้นำ ขวาบน — แข็งแรงและยังเร่งอยู่
  • เริ่มอ่อนแรง ขวาล่าง — ยังแข็งแรง แต่แรงส่งลดลง มักเป็นช่วงพักหรือเริ่มหมดแรง
  • ตามหลัง ซ้ายล่าง — อ่อนแอและยังแผ่วอยู่
  • กำลังฟื้น ซ้ายบน — ยังอ่อนแอ แต่เริ่มเร่งขึ้น เป็นโซนที่มักเห็นเงินเริ่มหมุนเข้า

3วงจรปกติหมุนตามเข็มนาฬิกา

ตามหลัง → กำลังฟื้น → ผู้นำ → เริ่มอ่อนแรง → ตามหลัง แต่ไม่จำเป็นต้องครบรอบ กลุ่มอาจเด้งกลับกลางทางได้

4ลูกศร

ลูกศร = ทิศทาง 5 วันล่าสุด · ลูกศรยาว = ขยับเร็ว · ชี้ขึ้นขวา = ดีขึ้น · ชี้ลงซ้าย = แย่ลง

5ขนาดจุด

ขนาดจุด = ความกว้าง (% หุ้นในธีมที่อยู่เหนือ MA50) · จุดใหญ่ = ขึ้นกันทั่วทั้งธีม ไม่ได้พึ่งหุ้นไม่กี่ตัว · วงกลวง = สมาชิกน้อยเกินกว่าจะคิดความกว้าง

6แตะดูเส้นทาง และซูมดูส่วนที่แน่น

แตะจุดเพื่อดูเส้นทางย้อนหลัง (เส้นเก่าจาง เส้นใหม่เข้ม) จะเห็นว่าธีมเดินมาจากไหน · แตะหลายธีมเพื่อเทียบกันได้

ซูม: กดปุ่ม + − ที่หัวแผนที่ หรือดับเบิลคลิก/แตะสองครั้งที่พื้นว่างเพื่อซูมเข้า · เมื่อซูมแล้วลาก (หรือใช้นิ้วเดียว) เพื่อเลื่อน และถ่างสองนิ้วเพื่อซูมเพิ่ม · บนคอมพิวเตอร์กด Ctrl/⌘ ค้างแล้วหมุนล้อเมาส์ได้ · กด “รีเซ็ต” เพื่อกลับมาดูทั้งหมด

ข้อควรระวัง — จุดที่อยู่ใกล้เส้นกลางจะพลิกโซนไปมาได้ง่ายตามความผันผวนรายวัน อย่าตีความการข้ามเส้นเพียงเล็กน้อยมากเกินไป · ธีมที่มีสมาชิก 5–7 ตัวจะกระโดดตามหุ้นตัวเดียวได้ (ดูคอลัมน์ n) · วิธีนี้ยังไม่ได้วัดย้อนหลังกับตลาดไทย ใช้เป็นรายการเฝ้าดูเพื่อหาหุ้นรายตัว ไม่ใช่สัญญาณซื้อ

ไฮไลต์น่าจับตา

คัดด้วยกติกาแบบเดียวกับบอร์ดสหรัฐ (ยังไม่ได้ปรับเกณฑ์ให้ตลาดไทย — ดูหมายเหตุท้ายส่วนนี้) แต่ละใบบอกเหตุผลพร้อมตัวเลข

ตารางจัดอันดับ

เรียงตามมัธยฐานผลตอบแทน 1 เดือนของหุ้นสมาชิกหลัก (ไม่ถ่วงน้ำหนักมูลค่าตลาด) · มีสรุปงบไตรมาสล่าสุดและ P/E ต่อธีม · กดหัวคอลัมน์เพื่อเรียงใหม่ กดชื่อธีมเพื่อดูหุ้นข้างใน

เส้นทาง 12 สัปดาห์ (สี = โซน · ตัวเลข = อันดับ)

อ่านจากซ้ายไปขวาคือจากอดีตมาปัจจุบัน สีบอกว่าธีมนั้นอยู่โซนไหนตอนสิ้นสัปดาห์ ตัวเลขคืออันดับมัธยฐานผลตอบแทน 1 เดือนในประเภทเดียวกัน (ธีมหลัก/ธีมย่อย) ดูว่าธีมไหนเพิ่งเปลี่ยนสี และอันดับไต่ขึ้นหรือร่วงไปพร้อมกัน

เฝ้าดู — ธีมที่ยังไม่จัดอันดับ

ธีมที่สมาชิกหลักน้อยหรือมูลค่าตลาดเล็กเกินกว่าจะคิดมัธยฐานได้อย่างน่าเชื่อถือ แสดงแยกไว้ที่นี่โดยไม่มีอันดับ โซน หรือไฮไลต์

วิธีคิดและที่มาของตัวเลข

ธีมและสมาชิก
รายชื่อธีมและหุ้นสมาชิกมาจากแผนที่ธีมหุ้นไทย (อ่านรายงานประจำปี 56-1 และ MD&A ของหุ้นเกือบทั้งตลาด แล้วจัดเป็นธีม) หุ้นหนึ่งตัวอยู่ได้หลายธีมถ้ารายได้ถึงเกณฑ์ ชั้นของสมาชิก: หลัก = รายได้จากธีมตั้งแต่ 20% ของทั้งบริษัท · หลัก? = ใกล้เกณฑ์ · เกี่ยวข้อง/ลูกค้า = แสดงในแผงรายละเอียดแต่ไม่เข้าตัวเลขใด ๆ ข้อมูลของแผนที่ ณ -
ดัชนีของธีม
ไม่มี ETF ธีมในตลาดไทย จึงสร้างดัชนีเอง: ทุกวันเอา มัธยฐาน ของผลตอบแทนรายวันของสมาชิกหลัก (ชั้นหลักและหลัก? ที่มูลค่าตลาด ≥ 1,000 ล้านบาท) แล้วทบต้น ใช้มัธยฐานเพราะหุ้นไทยมีตัวใหญ่ครอบงำกลุ่ม (เช่น GULF, SCC, AOT) ถ้าถ่วงน้ำหนักด้วยมูลค่าตลาดหุ้นตัวเดียวจะกลายเป็นทั้งธีม ข้อแลกเปลี่ยน: ธีมที่มีสมาชิกน้อยจะกระโดดตามหุ้นตัวเดียวได้
ตัวเลขของธีม
ผลตอบแทน 1D/1W/1M/3M = มัธยฐานของผลตอบแทนหุ้นสมาชิกแต่ละตัวในช่วงนั้น (5, 21, 63 วันทำการ) อันดับเรียงตาม 1M ส่วน RS และแผนที่ใช้ดัชนีธีมข้างบน จึงมีส่วนต่างเล็กน้อยระหว่างสองวิธี (แสดงทั้งคู่ในแผงรายละเอียด)
RS-Level
เส้นความแข็งแรง (ดัชนีธีม ÷ ดัชนี SET) ย้อนหลัง 63 วันทำการ (ราว 3 เดือน) ให้คะแนนเทียบกับธีมอื่นในประเภทเดียวกันในวันเดียวกัน แล้วตั้งให้ 100 เป็นค่ากลาง สูงกว่า 100 = แข็งกว่าเพื่อน
RS-Momentum
เช่นเดียวกัน แต่ดูย้อนหลัง 21 วันทำการ (ราว 1 เดือน) บอกว่ากำลังเร่งหรือแผ่ว สูงกว่า 100 = กำลังเร่งตัว
สี่โซน
ผู้นำ = Level และ Momentum สูงกว่า 100 · กำลังฟื้น = Level ต่ำกว่า 100 แต่ Momentum สูงกว่า · เริ่มอ่อนแรง = Level สูงกว่า 100 แต่ Momentum ต่ำกว่า · ตามหลัง = ต่ำกว่า 100 ทั้งคู่ เนื่องจากให้คะแนนเทียบกัน ครึ่งหนึ่งของธีมจะอยู่ต่ำกว่า 100 เสมอ ไม่มีโซนไหนว่าง ธีมหลักและธีมย่อยจัดอันดับแยกกัน เพราะธีมแคบขยับแรงกว่า ถ้ารวมกันธีมย่อยจะยึดปลายทั้งสองด้านเสมอ
ความกว้าง (Breadth)
สัดส่วนหุ้นสมาชิกที่ราคาปิดเหนือเส้นเฉลี่ย 50 วัน (MA50) นับเฉพาะหุ้นที่มีข้อมูลครบ ถ้าธีมมีสมาชิกที่วัดได้ต่ำกว่า 5 ตัวจะไม่คิดให้ (เกณฑ์ 5 ตัวตามเกณฑ์จัดอันดับของแผนที่ธีม ไม่ได้วัดใหม่กับตลาดไทย)
งบและ P/E
รายได้/กำไรสุทธิไตรมาสล่าสุดเทียบไตรมาสเดียวกันปีก่อน (YoY) และไตรมาสก่อน (QoQ) จาก TradingView; ถ้าไตรมาสฐานขาดทุนคิดเป็น % ไม่ได้ จะแสดงป้าย เช่น "พลิกกำไร" แทน; สรุปของธีมนับเฉพาะสมาชิกหลักที่รายงานไตรมาสเดียวกับตลาดส่วนใหญ่ · P/E = ราคาปิดล่าสุดของหน้านี้ ÷ กำไรต่อหุ้น 12 เดือน (EPS TTM) และมัธยฐานคิดเฉพาะตัวที่มีกำไร
แหล่งข้อมูล
ราคาปิดปรับปรุงแล้วจาก Yahoo Finance (yfinance) · ดัชนี SET จาก set.or.th (Yahoo ไม่มีประวัติดัชนี SET ที่ใช้ได้) · วันที่ของข้อมูลคือวันที่พบบ่อยที่สุดของทุกตัว ไม่ใช่วันที่ใหม่สุด เพราะบางครั้ง Yahoo ส่งข้อมูลมาขาดวันล่าสุดโดยไม่แจ้ง · ปฏิทินวันหยุดตลาด (SET_HOLIDAYS) ต้องเพิ่มปีใหม่เอง
