# Market Momentum

หน้ารายงานโมเมนตัมกลุ่มหุ้น สร้างอัตโนมัติจากข้อมูลราคาปิด (Yahoo Finance และ set.or.th)

- `hub.html` ศูนย์รวมทุกกระดาน (มี `nav.js` เป็นแถบเมนูกลางที่ทุกหน้าใช้ร่วมกัน)
- `index.html` ตลาดสหรัฐ (US) วันที่ของข้อมูลอยู่ใน `meta.json`
- `set.html` ตลาดหุ้นไทย (SET) วันที่ของข้อมูลอยู่ใน `meta_set.json`
- สองกระดานนี้อัปเดตแยกกัน คนละเวลา ไฟล์ทั้งหมดในที่นี้ถูกเขียนทับโดยระบบอัตโนมัติ ห้ามแก้ด้วยมือ
- ไม่ใช่คำแนะนำการลงทุน เป็นเพียงเครื่องมือช่วยดูว่ากลุ่มไหนน่าไปศึกษาต่อ
